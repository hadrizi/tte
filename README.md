# T text editor
Text editor that is(at least in the plans) powered by its own VM

# Current state
At its current state it's just a framework of a text editor based on [kilo](https://github.com/antirez/kilo) - it has some basic functionality inherent in a text editor but very unoptimized and lacks its main twist(VM)

# References
- https://wiki.xxiivv.com/site/varvara.html - ergonomic "computer system" that inspired the project
- https://github.com/antirez/kilo - small and simple text editor in C on which tte's backend is based
- https://en.wikipedia.org/wiki/Zilog_Z80 - old CPU on the basis of which tte's VM assembly is being designed
